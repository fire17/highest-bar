**The /highest-bar founding-vision kickoff protocol — batteries included.**

One repo carrying the complete `/highest-bar` skill and its entire nested-skill
closure (40+ skills, payloads, and tools), so a fresh machine gets the whole
highest-bar experience out of the box: verbatim vision preservation, the
force-activated quality stack, ladder-of-abstraction UX enforcement, budgets,
dual showcases, swarm orchestration, and darwin self-improvement loops.

## Install

```bash
git clone https://github.com/fire17/highest-bar && cd highest-bar
./install.sh        # skips skills you already have; --force overwrites
```

Requires `python3` (stdlib only) and `node ≥18` (for /impeccable). Everything
else is optional with written degrade paths — see the environment report the
installer prints, and `MAP.md`.

## Use

Paste `skills/highest-bar/assets/kickoff-message.md` (vision filled in) as a new
project's first message — or run:

- `/highest-bar <founding vision>` — the full kickoff protocol
- `/highest-bar-abstract` (`/hba`) — the hybrid: highest-bar + enforced
  ladder-of-abstraction UX
- `/ladder-abstraction` (`/ladder`) — derive a project-specific ladder for any
  interface, in any medium
